# PSY9511 Machine learning 

This repository contains my solutions for the weekly exercises from the machine learning course held in spring 2025 at the Department of Psychology. The exercises are from the 2023 version of "An introduction to statistical learning: With applications in Python", by James, G., Witten, D., Hastie, T., & Tibshirani, R.

## Week 1 - Introduction to machine learning
In this week's exercise we focused on getting a working programming environment up and running on our own computers, and did some simple data manipulation. We also answered somewhat theoretical questions to start our thought processes on how to use machine learning. 

## Week 2 - Basics of Regression and Classification
In this weeks assignment we gained practical experience in working with both data and statistical models, the most important skillset to retain from the course. 

## Week 3 - Variable selection and Regularization
In this weeks assignment we worked on variable selection and regularization of linear models, once again using the auto-dataset. We again tried to predict mpg based on various predictors, but this time using substantially more models and a more advanced approach. The two main learning goals:

- Gain practical experience with writing the code necessary for fitting and comparing a large(ish) number of models.
- Build intuition on overfitting, model evaluation, training and testing errors, and the impact of regularization (including variable selection).


## Week 4 - Model selection, validation, and testing
In this week's assignment we fitted and evaluated multiple classification models based on the Heart.csv dataset from ISL, predicting whether the subjects have a heart disease (AHD). The two main learning goals were:

- Gain more practical experience with writing analysis code, this time focusing specifically on reusing code through loops and functions.
- Compare approaches for model performance evaluation.

## Week 5 - Splines and tree-based methods
In previous weeks we had gotten detailed instructions on how to solve the exercises. This week we got free reign. We preprocessed the Credit.csv-dataset from ISL, and fitted non-linear models (GLM, GAM, RF, XGBoost) to predict Balance from the other variables. We reflected both on the choices we made and on the performance of the models.

## Week 6 - Unsupervised learning
It usually requires some work to set up your computer to run deep learning models. The purpose of this lab was to ensure we had all the prerequisites installed, and verify this by running some simple examples. We ran through all the example code in Chapters 10.9.1 to 10.9.4.

Handed in the performance curves from training three deep learning models. Reflection on the three performance curves (training, convergence, over-/underfitting).
